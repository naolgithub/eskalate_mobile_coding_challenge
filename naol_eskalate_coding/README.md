# Mobile Interview for Eskalate

Your challenge is to build a Flutter application that fetches and displays data about countries from a public REST API. This will test your skills in API integration, state management, UI development from a design, and local data persistence.
<br/>

## Task Overview

A Flutter application that fetches and displays country data from the REST Countries API, with search, detailed views, and a persistent favorites system.

## Installation

1. Install [Flutter](https://flutter.dev/docs/get-started/install) for your platform.
2. Clone this repository or download the source code.
3. Open a terminal window and navigate to the project directory.
4. Run `flutter pub get` to install dependencies.
5. Connect a device or emulator.
6. Run `flutter run` to start the app.
